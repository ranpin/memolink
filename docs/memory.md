# MIRIX记忆系统设计文档

## 1. 概述

MIRIX记忆系统基于人类记忆模型设计，包含多种类型的记忆存储，用于存储和管理不同类型的信息。系统通过模拟人类记忆的工作方式，实现信息的存储、检索和管理。

## 2. 记忆系统架构

### 2.1 记忆类型

#### 2.1.1 核心记忆 (Core Memory)
存储最基本和重要的信息块，是系统运行的核心数据。

**管理器**: CoreMemoryBlockManager
**存储表**: core_memory_block

**特征**:
- 高优先级存储
- 不易丢失
- 快速访问

#### 2.1.2 事件记忆 (Episodic Memory)
存储个人经历和事件相关信息，包含时间、地点、参与者等上下文信息。

**管理器**: EpisodicMemoryManager
**存储表**: episodic_memory

**特征**:
- 时间序列化存储
- 包含丰富上下文
- 支持情感标记

#### 2.1.3 语义记忆 (Semantic Memory)
存储概念性知识和事实信息，如词汇、概念、规则等。

**管理器**: SemanticMemoryManager
**存储表**: semantic_memory

**特征**:
- 结构化知识存储
- 概念关联网络
- 分类管理

#### 2.1.4 程序记忆 (Procedural Memory)
存储技能和过程性知识，如如何执行特定任务。

**管理器**: ProceduralMemoryManager
**存储表**: procedural_memory

**特征**:
- 步骤化存储
- 熟练度跟踪
- 条件触发

#### 2.1.5 资源记忆 (Resource Memory)
存储多媒体资源文件的元信息，包括图像、音频、视频等。

**管理器**: ResourceMemoryManager
**存储表**: resource_memory

**特征**:
- 文件元信息管理
- 多媒体类型支持
- 路径索引

#### 2.1.6 知识库 (Knowledge Vault)
存储结构化知识和信息，如文档、文章等。

**管理器**: KnowledgeVaultManager
**存储表**: knowledge_vault

**特征**:
- 结构化存储
- 来源追踪
- 可靠性评估

#### 2.1.7 归档记忆 (Archival Memory)
存储长期保存的历史数据，用于备份和历史查询。

**管理器**: ArchivalMemoryManager
**存储表**: archival_memory

**特征**:
- 长期存储
- 压缩优化
- 策略管理

#### 2.1.8 回忆记忆 (Recall Memory)
存储记忆检索过程和结果，用于优化检索算法。

**管理器**: RecallMemoryManager
**存储表**: recall_memory

**特征**:
- 检索过程记录
- 相关性评分
- 性能监控

## 3. 记忆管理器设计

### 3.1 通用接口
所有记忆管理器都实现以下通用接口：

```cpp
class MemoryManager {
public:
    virtual bool add(...) = 0;
    virtual bool update(...) = 0;
    virtual bool delete(...) = 0;
    virtual MemoryRecord get(...) = 0;
    virtual std::vector<MemoryRecord> search(...) = 0;
};
```

### 3.2 核心方法

#### 3.2.1 添加记忆 (add)
将新的记忆信息添加到系统中。

参数：
- userId: 用户ID
- 相关内容数据
- 元数据

返回值：
- bool: 操作是否成功

#### 3.2.2 更新记忆 (update)
更新已存在的记忆信息。

参数：
- memoryId: 记忆ID
- 更新的内容数据
- 元数据

返回值：
- bool: 操作是否成功

#### 3.2.3 删除记忆 (delete)
从系统中删除记忆信息。

参数：
- memoryId: 记忆ID

返回值：
- bool: 操作是否成功

#### 3.2.4 获取记忆 (get)
根据ID获取特定的记忆信息。

参数：
- memoryId: 记忆ID

返回值：
- MemoryRecord: 记忆记录

#### 3.2.5 搜索记忆 (search)
根据关键词搜索相关的记忆信息。

参数：
- userId: 用户ID
- keyword: 搜索关键词

返回值：
- std::vector<MemoryRecord>: 匹配的记忆记录列表

## 4. 记忆存储策略

### 4.1 存储优先级
1. 核心记忆：最高优先级，持久化存储
2. 事件记忆：高优先级，长期存储
3. 语义记忆：中等优先级，长期存储
4. 程序记忆：中等优先级，长期存储
5. 资源记忆：根据资源重要性分级存储
6. 知识库：高优先级，长期存储
7. 归档记忆：低优先级，压缩存储
8. 回忆记忆：中等优先级，定期清理

### 4.2 存储优化
- 使用索引提高检索速度
- 定期清理过期数据
- 压缩存储大文件元信息
- 分区存储不同类型记忆

## 5. 记忆检索机制

### 5.1 检索方式
1. 精确匹配检索
2. 模糊匹配检索
3. 向量相似性检索
4. 时间范围检索

- 并行处理多个检索请求
