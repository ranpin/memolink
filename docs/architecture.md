# MIRIX系统架构设计文档

## 1. 系统概述

MIRIX是一个多模态数据处理和记忆管理系统，旨在模拟人类记忆系统来存储、管理和检索多模态数据。系统采用模块化设计，包含数据采集、数据管理、记忆系统、AI模型集成等多个层次。

### 2.2 核心组件

1. **数据采集层**：负责从各种输入源收集数据
2. **数据管理层**：协调和管理多模态数据流
3. **记忆系统层**：模拟人类记忆系统存储和检索信息
4. **模型与AI层**：集成AI模型进行数据分析和处理
5. **应用层**：提供用户交互界面和演示程序

## 3. 模块详细设计

### 3.1 数据采集层

#### 3.1.1 摄像头捕获模块 (CameraCaptureManager)
- 功能：捕获摄像头图像和视频
- 技术：基于OpenCV实现
- 支持格式：JPEG图像、MP4视频
- 特性：支持单次和持续捕获

#### 3.1.2 音频捕获模块 (AudioCaptureManager)
- 功能：录制系统音频
- 技术：基于PortAudio实现
- 支持格式：WAV音频
- 特性：支持单次和持续录制

#### 3.1.3 屏幕活动跟踪模块 (ScreenActivityTracker)
- 功能：捕获屏幕截图和跟踪屏幕活动
- 技术：基于ScreenCaptureKit和系统命令实现
- 支持格式：PNG图像
- 特性：支持单次和持续截图

#### 3.1.4 系统事件管理模块 (SystemEventManager)
- 功能：处理系统级事件
- 特性：记录系统事件数据

### 3.2 数据管理层

#### 3.2.1 多模态数据管理器 (MultimodalDataManager)
- 功能：统一管理所有多模态数据的捕获和存储
- 特性：协调各个采集模块，提供统一接口

#### 3.2.2 存储管理器 (StorageManager)
- 功能：封装数据库操作
- 技术：基于SQLite实现
- 特性：提供统一的数据库访问接口

#### 3.2.3 事务管理器 (TransactionManager)
- 功能：管理数据库事务
- 特性：确保数据操作的原子性和一致性

### 3.3 记忆系统层

#### 3.3.1 核心记忆块管理器 (CoreMemoryBlockManager)
- 功能：管理核心记忆数据块

#### 3.3.2 事件记忆管理器 (EpisodicMemoryManager)
- 功能：存储个人经历和事件记忆

#### 3.3.3 语义记忆管理器 (SemanticMemoryManager)
- 功能：存储概念性知识和事实

#### 3.3.4 程序记忆管理器 (ProceduralMemoryManager)
- 功能：存储技能和过程性知识

#### 3.3.5 资源记忆管理器 (ResourceMemoryManager)
- 功能：存储多媒体资源文件信息
- 特性：存储所有捕获的多模态数据

#### 3.3.6 知识库管理器 (KnowledgeVaultManager)
- 功能：管理结构化知识

#### 3.3.7 归档记忆管理器 (ArchivalMemoryManager)
- 功能：存储长期归档数据

#### 3.3.8 回忆记忆管理器 (RecallMemoryManager)
- 功能：管理回忆过程和记忆检索

### 3.4 模型与AI层

#### 3.4.1 模型管理器 (ModelManager)
- 功能：整合多种AI模型
- 特性：提供统一的模型调用接口

#### 3.4.2 QwenAPI接口
- 功能：集成通义千问API
- 特性：支持文本生成和多模态处理

#### 3.4.3 嵌入索引管理器 (EmbeddingIndexManager)
- 功能：管理向量嵌入和索引
- 特性：支持相似性搜索

## 4. 数据流设计

### 4.1 数据采集流程
1. 用户触发数据采集命令
2. 多模态数据管理器协调相应采集模块
3. 采集模块捕获数据并保存到文件系统
4. 数据元信息存储到资源记忆管理器

### 4.2 数据存储流程
1. 采集模块将数据文件保存到文件系统
2. 采集模块调用资源记忆管理器存储元信息
3. 资源记忆管理器将元信息存储到数据库

### 4.3 数据检索流程
1. 用户发起检索请求
2. 相应记忆管理器查询数据库
3. 返回匹配的记忆数据给用户

## 5. 接口设计

### 5.1 内部接口
各模块之间通过C++类和方法进行交互，遵循面向对象设计原则。

### 5.2 外部接口
系统通过命令行界面和演示程序与用户交互。

## 6. 部署架构
系统为单机部署架构，所有组件运行在同一台机器上，数据存储在本地SQLite数据库中。
