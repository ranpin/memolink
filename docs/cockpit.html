核心方法

座舱域天然把 memolink 的独有机制变成「看得见、且非它不可」的功能——而不是一个套了记忆库的聊天机器人。

SUPERSEDE 版本化

搬家后家庭地址从西湖区改成滨江区：旧记忆标失效但保留，新记忆入库并建双向链。检索只返回当前值，history 可回溯整条演化。

类型特化检索

「上次充电在哪」路由到 episodic（+时间衰减），「座椅加热怎么开」路由到 procedural，偏好类路由到 semantic——意图识别驱动检索，不是全类型一起搜。

多驾驶员治理

换驾驶员李四后，张三的私人记忆（家庭住址、孩子学校）被 GovernanceFilter 拦截、对李四不可见；而共享记忆（车辆电池/续航）仍可见。隐私按 owner+scope 强制端侧隔离。

五操作消解

每轮用户话经本地 4B 提取候选事实，再由三层消解判定 CREATE / SUPERSEDE / NOOP——查询轮天然 NOOP，不污染记忆库。
