# MIRIX - 多模态记忆系统

MIRIX是一个仿人类记忆系统的多模态数据处理框架，能够捕获、存储和管理图像、音频、屏幕截图等多种类型的数据，并将其组织成类似人类记忆的结构。

## 功能特性

### 多模态数据处理
- **图像捕获**：支持摄像头图像捕获和存储
- **音频录制**：支持系统音频录制和存储
- **屏幕截图**：支持屏幕内容捕获和存储
- **持续捕获**：支持定时自动捕获各类数据

### 仿人类记忆系统
系统实现了完整的人类记忆模型，包括：
- **核心记忆**：存储最基本和重要的信息块
- **事件记忆**：存储个人经历和事件相关信息
- **语义记忆**：存储概念性知识和事实信息
- **程序记忆**：存储技能和过程性知识
- **资源记忆**：存储多媒体资源文件的元信息
- **知识库**：存储结构化知识和信息
- **归档记忆**：存储长期保存的历史数据
- **回忆记忆**：存储记忆检索过程和结果

### AI模型集成
- **通义千问API**：集成Qwen大模型进行文本处理
- **向量检索**：支持基于向量的相似性搜索
- **多模态处理**：支持图像、音频和文本的联合处理

### 数据管理
- **SQLite数据库**：使用SQLite进行数据持久化存储
- **事务管理**：支持数据库事务确保数据一致性
- **索引优化**：建立索引提高数据检索效率

## 多模态数据处理详解

### 数据获取
系统支持多种类型的数据获取：
- **文本数据**：用户输入、系统响应、对话历史等
- **图像数据**：摄像头捕获、屏幕截图等
- **音频数据**：系统音频录制等

### 数据存储
所有数据都存储在SQLite数据库中，不同类型的数据存储在不同的表中：
- **文本数据**：存储在recall_memory表中，包含用户ID、会话ID、消息类型、内容等字段
- **图像/音频数据**：存储在resource_memory表中，包含文件路径、资源类型、摘要等字段

### 数据检索
系统支持多种数据检索方式：
- **传统查询**：基于用户ID、会话ID、时间等元数据的查询
- **向量检索**：使用CLIP模型生成文本和图像的embedding，支持跨模态相似性搜索
- **混合检索**：结合传统查询和向量检索的结果

## 记忆系统设计

系统实现了8种不同类型的记忆，每种记忆都有专门的管理器和存储表：

### 1. 回忆记忆 (Recall Memory)
存储对话历史和记忆检索过程，是系统中最活跃的记忆类型。
- **管理器**：RecallMemoryManager
- **存储表**：recall_memory
- **主要字段**：user_id, agent_id, session_id, message_type, content, embedding

### 2. 资源记忆 (Resource Memory)
存储多媒体资源文件的元信息，包括图像、音频、屏幕截图等。
- **管理器**：ResourceMemoryManager
- **存储表**：resource_memory
- **主要字段**：user_id, agent_id, session_id, filename, resource_type, summary, path, embedding

### 3. 用户和会话管理
管理用户信息和会话状态，为其他记忆类型提供上下文支持。
- **用户管理器**：UserManager
- **会话管理器**：SessionManager
- **存储表**：user, session

### 4. Agent管理
管理AI代理信息，支持不同类型的AI代理。
- **管理器**：AgentManager
- **存储表**：agent

## 用户交互测试

系统提供了完整的测试脚本用于验证功能：

### 测试脚本
- **test_chat_with_model.cpp**：主要的交互测试程序，支持文本对话和跨会话历史查询
- **其他测试程序**：针对特定功能模块的测试

### 测试流程
1. 初始化数据库和系统组件
2. 创建或获取用户和Agent
3. 创建新会话
4. 读取用户输入
5. 构建上下文信息（包括历史对话和相关记忆）
6. 调用模型生成响应
7. 保存对话记录到回忆记忆
8. 输出响应给用户
9. 结束会话并清理资源

### 跨会话历史查询
系统支持跨会话历史记录查询，可以查询用户最近几次会话的历史记录，提供更丰富的上下文信息。

# MIRIX - 智能记忆系统

MIRIX是一个先进的记忆管理人工智能系统，旨在提供全面的记忆存储、检索和管理功能。

## 功能特性

- 多种记忆类型管理（核心记忆、情景记忆、语义记忆、程序性记忆、资源记忆、知识库等）
- 数据库存储和管理
- AI模型集成（支持真实API和模拟模式）
- 命令行界面和API服务
- 多模态数据处理（文本、图像等）

## 配置说明

系统通过`config.ini`文件进行配置:

```ini
# MIRIX配置文件

[api]
key=your_api_key_here

[model]
text_model_name=qwen-plus
embedding_model_name=text-embedding-v1
multimodal_model_name=qwen-vl-plus

[database]
db_path=mirix.db
```

### 获取API密钥

1. 访问阿里云百炼平台 (https://help.aliyun.com/zh/bailian)
2. 创建应用并获取API密钥
3. 将密钥填入config.ini文件的`key`字段

### 配置模型参数

系统支持三种类型的模型:
- 文本模型: 用于文本生成任务
- 嵌入模型: 用于文本嵌入向量生成
- 多模态模型: 用于图像和文本混合处理
